# Universal Multilingual AI Assistant

An all-in-one AI app powered by Gemini API that supports:
- All global languages (Multilingual).
- Text processing and reasoning.
- Image recognition and visual guidance.

## How to Run Locally:
1. Clone the repository: `git clone <your-repo-link>`
2. Install requirements: `pip install -r requirements.txt`
3. Run Streamlit app: `streamlit run app.py`
